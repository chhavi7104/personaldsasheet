# A2Z DSA Tracker — Personal React App

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Features in this first version

- No Plus section
- Topic sidebar
- 474-topic target structure
- Search
- Difficulty filter
- Revision filter
- Solved / unsolved filter
- Question links
- Theory links
- GitHub solution links when supplied
- Per-question remarks
- LocalStorage persistence
- Progress dashboard
- Reset progress

## Data

The current generated JSON files are combined into `src/data/dsaData.json`.
The Basics/Sorting/Arrays sections are reserved in the UI and can be dropped in later
without changing the app architecture.
